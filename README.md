# Projects

A monorepo of standalone projects, each in its own subfolder with its own README,
dependencies, and (where applicable) its own GitHub Actions workflow.

| Project | Description | Live demo |
|---|---|---|
| [`equal-earth-projection-benchmark`](equal-earth-projection-benchmark/) | Interactive world data explorer (population density, forest cover, CO₂ emissions, urbanization) as an animated time-series choropleth, plus a Web Mercator vs. Equal Earth projection-distortion comparison. | [Demo](https://pratyush-dh.github.io/projects/equal-earth-projection-benchmark/) |
| [`fia-forest-stand-profile`](fia-forest-stand-profile/) | US forest inventory explorer built on live USDA FIADB-API queries — volume, biomass, growth, mortality, removals, sawlog stock, and forest area by stand-size class, state and county level, with a zoomable choropleth map and per-acre density views. | [Demo](https://pratyush-dh.github.io/projects/fia-forest-stand-profile/) |
| [`rainfall-relief`](rainfall-relief/) | US annual precipitation as terrain (3D relief beside real elevation, plus a 30-year pulse), as drought indices (SPI and six more, with regional dashboards), and as zoomable equal-area hexagons down to 1 acre that zoom to a state on click. Pick any year range, upload your own yearly rasters, and export per-year maps and a GIF. | [Pulse](https://pratyush-dh.github.io/projects/rainfall-relief/pulse.html) · [Drought](https://pratyush-dh.github.io/projects/rainfall-relief/drought.html) · [Hex map](https://pratyush-dh.github.io/projects/rainfall-relief/hexrain.html) |
| [`pokhara-sight`](pokhara-sight/) | A 360-degree line-of-sight sweep from seven Pokhara viewpoints (Sarangkot, World Peace Pagoda, Kahun Danda, Pumdikot, Kaskikot, Naudanda, Lakeside) to nine Himalayan giants, from a 30 m Copernicus surface model with earth curvature and refraction, animated with a live panorama. | [Demo](https://pratyush-dh.github.io/projects/pokhara-sight/) |

More projects will be added here over time.
