Forest Stand Profile
How much wood volume, living biomass, and merchantable timber each US state holds — how fast it's growing versus dying versus being cut — and whether that wood sits in young regenerating stands or old mature ones. Every figure comes from the federal government's tree-by-tree inventory of American forests.
What this shows
Volume, biomass, growth, mortality, removals, sawlog stock, and forest area for every US state, broken down by stand age — seedling/sapling → poletimber → sawtimber — as totals or per-acre density. Pick a state to zoom in and see the same breakdown county by county.
Built from
Live queries against USDA's own FIADB-API — the same estimation engine behind their official EVALIDator tool — run for each state's most current forest survey. Nothing simulated or interpolated; sampling error is carried through.
Why it matters
EVALIDator, USDA's own query tool, already supports custom breakdowns and per-acre denominators — but one state and one query at a time, with no cross-state map. USDA's separately published state bulletins are static, fixed-format tables. This page runs the same kind of live query across every state at once, on one map.
